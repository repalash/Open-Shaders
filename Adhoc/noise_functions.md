# Noise functions (Inigo Quilez)

Reference implementations of gradient/value noise and their analytic derivatives
by Inigo Quilez. The shader sources live on Shadertoy (viewer runs the code
interactively); they are linked here rather than mirrored because Shadertoy's
default content licensing and its Cloudflare protection prevent redistributing
the code verbatim.

- Latest: https://www.shadertoy.com/view/4tGGWW
- Main: https://www.shadertoy.com/view/MtV3W1

See also Inigo Quilez's write-ups on noise and its derivatives:
- https://iquilezles.org/articles/morenoise/
- https://iquilezles.org/articles/gradientnoise/
- https://iquilezles.org/articles/dirtnoise/
