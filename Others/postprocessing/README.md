# postprocessing

Effect shaders from **postprocessing**, a post-processing library for three.js
by Raoul van Rüschen (vanruesc). GLSL for effects (bloom, bokeh/DOF, SSAO, SMAA,
chromatic aberration, glitch, god rays, tone mapping, LUT, outline, …) and the
Photoshop-style blend functions.

- Source: https://github.com/vanruesc/postprocessing/tree/master/src/effects/glsl

- `effects/blending-glsl/` — blend-mode functions (`src/effects/blending/glsl`)
