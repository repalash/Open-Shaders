# Wagner

Post-processing fragment shaders from **Wagner**, an efficient, modular effect
composer for three.js by Jaume Sanchez (spite). Includes blurs, bloom, DOF/bokeh,
chromatic aberration, film/vignette/noise, glitch, edge detection, tone mapping,
FXAA and many stylised effects.

- Source: https://github.com/spite/Wagner/tree/master/fragment-shaders
