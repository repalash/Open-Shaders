# processing-postfx (PostFX)

Post-effect fragment shaders from **PostFX**, a simple post-effects library for
Processing by cansik. Effects include bloom/bright-pass, blur, sobel, toon,
vignette, RGB split / chromatic aberration, pixelate, noise, grain glitch,
saturation/vibrance, brightness/contrast, exposure, tone mapping, denoise,
grayscale and invert.
