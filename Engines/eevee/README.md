# EEVEE shaders

Real-time PBR shaders from Blender's **EEVEE** (Extra Easy Virtual Environment
Engine) draw engine. Includes the GLSL shader library plus the newer `.bsl.hh`
Blender Shader Language sources (deferred/forward lighting, depth of field,
motion blur, screen-space reflection/refraction, shadows, volumes, film, etc.).
